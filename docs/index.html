MazeMouse 是苏州大学电子信息学院《电子系统设计》课程设计项目，服务于电脑鼠竞赛中最需要反馈的环节：连接、探索、回溯、优化，并在同一个界面里把数据与图形对应起来。

原生桌面架构确保低延迟接收，轨迹优先的界面让每一次移动、每一面墙、每一个传感器状态都即时可见。

串口通信实时轨迹墙体绘制传感器监控路径回放最短路径数据导出2D / 3D
Quietly capable

四组能力，覆盖从连接到交付。

少一点切换，多一点看见。

01

实时轨迹可视化

2D / 3D 双模式显示，动态轨迹与渐隐效果，实时呈现电脑鼠的位置、朝向与角度。

02

串口通信管理

自动检测可用串口，支持波特率、数据位、停止位与校验位配置，并实时统计通信速率。

03

传感器与墙体

前后左右传感器状态实时显示，并根据电脑鼠朝向自动判断、更新迷宫墙体。

04

回放与路径优化

自动保存运行轨迹，支持多轨迹回放对比、快照导出，以及最短路径计算与下发。
